DompetKeluarga — a household budget site in Indonesian that runs fully offline from static files: track income and expenses, set a monthly limit per category with over-budget warnings, and read monthly reports with hand-drawn charts. Data lives in the browser's localStorage, so nothing ever leaves the device.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The site has five hash-routed pages: Beranda (dashboard with a six-month income-vs-expense bar chart and a category donut), Transaksi (add, edit, delete and filter every transaction), Anggaran (per-category limits with progress bars and warnings), Laporan (monthly report with a month-over-month comparison), and Pengaturan (household data, JSON backup, reset to the sample data).
